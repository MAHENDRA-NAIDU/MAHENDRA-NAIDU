# 🚀 GitHub Profile Setup Guide

Welcome to your complete, premium animated 2026 GitHub Profile README project! Follow this step-by-step guide to launch your profile README on GitHub.

---

## 📋 Prerequisites

1. A **GitHub Account**.
2. Git installed locally on your system.

---

## 🛠️ Step 1: Create Your GitHub Profile Repository

1. Log in to [GitHub](https://github.com).
2. Click the **`+`** icon in the top-right corner and select **New repository**.
3. Set the **Repository name** to match your exact GitHub Username (e.g., if your username is `mahendra-naidu`, name the repository `mahendra-naidu`).
   > 💡 **Note**: GitHub will show a special banner: *"You found a secret! [username] is a special repository that you can use to add a README.md to your GitHub profile."*
4. Make sure the repository visibility is set to **Public**.
5. Check **Initialize this repository with a README** (or push this project directly).

---

## 📦 Step 2: Push Files to GitHub

Initialize git locally inside this directory and push to your newly created repository:

```bash
# Initialize git repository
git init

# Add all files
git add .

# Commit changes
git commit -m "feat: initial release of 2026 premium animated github profile"

# Change branch to main
git branch -M main

# Link your GitHub repository (replace YOUR-USERNAME with your actual username)
git remote add origin https://github.com/YOUR-USERNAME/YOUR-USERNAME.git

# Push to GitHub
git push -u origin main
```

---

## 🐍 Step 3: Enable Contribution Snake Workflow

1. Go to your GitHub repository on github.com.
2. Click on the **Actions** tab.
3. If prompted, click **"I understand my workflows, go ahead and enable them"**.
4. Select **Generate Contribution Snake** from the left sidebar.
5. Click **Run workflow** -> **Run workflow** (Manual Trigger).
6. Once the workflow finishes (green checkmark), it automatically creates an `output` branch containing the snake animation SVG!

---

## ✨ Step 4: Verify Your Profile

Visit your main profile page:
`https://github.com/YOUR-USERNAME`

Your new high-tech animated profile will now be live with glassmorphism aesthetics, interactive typing effects, live stats, contribution snake, and responsive project cards!
